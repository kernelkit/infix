# Infix

Infix is a Buildroot based Linux network operating system, configured
over NETCONF, RESTCONF and a CLI from YANG models.  The developer
documentation is in `doc/`, starting with `doc/developers-guide.md`,
and contribution rules are in `.github/CONTRIBUTING.md`.

Before building, testing, changing, committing or pushing anything in
this tree, invoke the `infix-dev` skill in `.claude/skills/infix-dev/`.
It names the document to read for the task at hand and lists the rules
reviewers enforce.  When the skill and the docs disagree, the docs win.
